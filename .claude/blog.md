# news_info.html

`retroweb/news_info.html` is the public About & News page. Chris edits
the entries and the About section on that page. Agents must not rewrite
that prose.

`retroweb/about.html` stays the Help page. The public site does not link
it. Help on `super_secret.html` and on the machine pages still opens it.
That page follows [about.md](about.md).

## Allowed

- Navigation, header, and footer chrome only — the same shared pagebar /
  titlebar / theme / footer wiring other machines use.
- Structural fixes that keep those chrome pieces in sync with the rest of
  the site (e.g. a shared script path, favicon link, theme bootstrap).

## Not allowed

- Editing body copy: headings, paragraphs, entries, or any other content
  between the header and the footer.
- Adding or removing content sections.
- "While we're here" cleanup of the prose.

If a task would need a content change on this page, leave the file alone
and tell Chris — he edits the entries himself.
