Running test ROM

HIGH SCORE is kept in this browser after refresh — the real board has no battery and loses it when you pull the plug. Reset clears the saved table and restarts the cabinet.

DIP switches

Same operator bank as inside the cabinet (Midway service manual). Settings survive a refresh the way the physical switches do. Difficulty and ghost names are solder pads on some boards; cabinet type is an edge-connector jumper. The game samples these on the next credit.
