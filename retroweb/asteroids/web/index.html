ROM sockets

This page ships a hardware self-test ROM, not Atari Asteroids. Those ROMs are still under copyright and are not included or downloaded. Load a complete original-board set (MAME asteroid zip, or the loose chips: program 035145/035144/035143 plus vector 035127). Each chip is identified by its usual name and checked by size, not a particular CRC. Extra files are ignored. The set stays in this browser.

Running test ROM

HIGH SCORE is kept in this browser after refresh. The real board has no battery and loses it when you pull the plug. Reset clears the saved table and restarts the cabinet.

DIP switches

Set board DIP switches just like on the real arcade cabinet. These persist in this browser the same way physical switches survive a power cycle.
