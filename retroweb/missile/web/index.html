Missile Command Arcade

Atari Missile Command (1980) board. MOS 6502 at 1.25 MHz, trackball, three launchers, POKEY sound.

ROM sockets

This page ships a hardware self-test ROM, not Atari Missile Command. Those ROMs are still under copyright and are not included or downloaded. Load a complete original-board set (MAME missile zip, or the six loose program chips 035820-02, 035821-02, 035822-03e, 035823-02, 035824-02 and 035825-02). The 035826-01 PROM is optional. Each chip is identified by its usual name and checked by size, not a particular CRC. Extra files are ignored. The set stays in this browser.

Running test ROM

HIGH SCORE is kept in this browser after refresh. The real board keeps its table in work RAM with no battery, so it starts over at power-up. Reset clears the saved table and restarts the cabinet.

DIP switches

Set board DIP switches just like on the real arcade cabinet. These persist in this browser the same way physical switches survive a power cycle.

ROM set not loaded

Need a complete original-board set: a MAME missile zip, or the six loose 2K program chips 035820-02.h1, 035821-02.jk1, 035822-03e.kl1, 035823-02.lm1, 035824-02.np1, 035825-02.r1, or one 12K program.bin. The 32-byte PROM 035826-01.l6 is optional. Each chip is checked by size, not a particular CRC. Extra files are ignored.
