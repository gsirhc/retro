Load address:    Start (PC):

Two ways to read it. START just runs the reader — spooling the tape through the 88-2SIO for a bootstrap loader you are already running (the boot PROM, or ~20 bytes keyed in at the front panel — see "Load it yourself"). AUTO-LOAD is the shortcut: it resets the machine, keys a serial bootstrap into the top of RAM, runs it, and answers BASIC's cold-start prompts for you. At "Realistic" speed 8K BASIC really takes minutes either way.

▣ Insert Diskette — drive A: ×

Diskette library — served from disks/ :

 

...or load a .dsk image from disk:

no file selected

Standard MITS 8″ images are 337,568 bytes (77×32×137). See disks/README.md for where to get CP/M and application disks.

…or insert a blank diskette. Unformatted is real 8″ media as it ships: boot CP/M from drive A, run FORMAT, give the DISK command and pick this drive first. Formatted skips that and is ready to write to right away. Either way, SAVE the drive to download the .dsk.

Cassette library — served from tapes/ :

 

...or load a .cas file you saved earlier:

no file selected

...or a fresh blank tape — record with CSAVE"name" (press REC), then SAVE .CAS on the deck to keep it.

Once inserted, the deck shows which CLOAD name the tape holds. In BASIC: CLOAD"name", then press PLAY; CSAVE"name" records. REW between the two.
