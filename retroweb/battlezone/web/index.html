ROM sockets

This page ships a hardware self-test ROM, not Atari Battlezone. Those ROMs are still under copyright and are not included or downloaded. Load the ROMs yourself: bzone.zip or bzonea.zip, or the loose chips. That's program 036409 to 036414, vector 036421 and 036422, and the Math Box PROMs 036174 to 036180. Each chip is identified by its part number and checked by size, not a particular CRC. The vector state PROM 036408 and any extra files are ignored. The set stays in this browser.

Running test ROM

HIGH SCORE is kept in this browser after refresh. The real board has no battery and loses it when you pull the plug. Reset clears the saved table and restarts the cabinet.

DIP switches

Set board DIP switches just like on the real arcade cabinet. These persist in this browser the same way physical switches survive a power cycle.
