Help / About

This site emulates "Old Ass Computers" running entirely in your browser. The emulator cores are written from scratch in C++ and compiled to a WebAssembly module. The module is downloaded to the browser, allowing the emulator to execute all hardware simulation locally. There are no virtual machines or third-party emulator engines involved.

Commercial Software vs. Shareware / Freeware

This site does not host commercial software or game ROMs where active rights holders still enforce their copyrights. Some titles like Altair BASIC and CP/M have long since been redistributed among the retro community and therefore are included.

This site does supply shareware and freeware titles. They are unmodified from their original form and still belong to their respective owners.

If you are an active rights holder of any software supplied here and would like it removed, please contact me below.

Removable Media Formats

Media such as floppy disks, CDs, cassette/paper tapes and ROMs must be loaded from image files. Each emulator will have instructions on which types of files are supported. If you have physical media, you will need to convert them to the expected images. This site does not support physical devices connected through USB or other means.

Hard Drives

Hard disk images are stored in your browser's IndexedDB and changes are saved every few seconds so you don't have to worry about losing your data. To be sure your hard drive is synced, power off the machine before navigating away from the page. It's also recommended that you download your hard drive images periodically as a backup.

High Scores

For arcade games with high scores, the emulators will store your scores in browser storage so they persist across sessions. You can reset your high scores at any time.

Browser Support

Chromium-based browsers are recommended as most testing is done in Chrome. However, the site should run fine in all major browsers. If you use privacy extensions or privacy-focused browsers, you may encounter issues with sound, fullscreen or browser storage.

System Requirements

The emulators should run on any modern desktop, laptop, tablet or even smartphone. The heavier emulators, such as the 486, may suffer performance issues on lower-end or older devices. Since the emulators run in the browser, you should ensure you have at least 1GB of available RAM after the browser is loaded.

About the Creator

Hello, I'm Chris, the creator of this site. I've been a professional software engineer for over 25 years and a computer geek for much longer than that. In recent years I've dabbled in retro computing but never acquired era-correct hardware as it seems expensive and prone to failure. So, I set out to create this site so I could relive the retro days as closely as possible without the headaches of the real thing.

Site Goals

When I set out to create this site, I came up with the following goals:

  • All hardware emulation must be able to run in a web browser
  • Hardware emulation is accurate down to the individual CPU instruction
  • All emulatators must be written from scratch
  • The core systems must function at real-time speeds
  • Only period-correct storage devices can be used to load software
  • The systems must be thoroughly tested with unit and end-to-end automation
