Hard disk

      

        Checking for a saved hard disk…
      

      

        
        
        Changes you make while running (FORMAT, COPY, installing
          software) are saved automatically in this browser every few seconds or on
          power off, and restored on your next visit. Both take effect at the next
          power-on -- a real fixed disk can't be swapped while the machine is
          running.
      

      

        
        
        A real file on your own disk, independent of this browser's
          storage -- download it as a backup, or upload a previously-downloaded (or
          otherwise obtained) image to use as C:. Also takes effect at the next
          power-on.
      

    


    

      
Removable media

      

        One 3.5″ 1.44MB floppy bay (drive A:) -- also
          reads genuine double-density 720KB 3.5″ media. Mount a raw .IMG of
          exactly one of those two sizes.
      

      

        One 2x ATAPI CD-ROM bay (drive D:) -- mount a raw .ISO
          (2048-byte sectors). "Insert FreeDOS CD…" under Freeware Disks
          & Drivers fetches FreeDOS's own official install/live CD on
          demand (a ~400MB download) -- it is not fetched at page load, since
          C: already ships with FreeDOS installed and does not need it to
          boot.
      

    


    

      
Software compatibility

      

        Ships with FreeDOS 1.3 on C:, and runs real PC-DOS/
          MS-DOS 6.x-era real-mode software the same way -- this is currently a
          real-mode-only 80486DX2, so protected mode, paging, the on-die FPU, a
          sound card, and VESA/256-color VGA modes aren't implemented yet
          (Milestone 1 of a multi-milestone build -- see
          PC486_REVIEW.md
          for what's next). Keyboard and the internal PC speaker only for now.
      

      

        Disk images aren't included or hosted here (beyond the
          freely-licensed FreeDOS install/live CD and HDD image) -- commercial
          software remains copyrighted. You'll need to find your own compatible
          disk image and mount it yourself.
