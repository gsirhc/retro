Wozmon monitor

Genuine 1976 Apple-1 Wozmon — uppercase, hex only:
  • AAAA examine byte AAAA · AAAA.BBBB examine a block
  • AAAA: BB CC store bytes at AAAA · AAAA R run at AAAA (never returns — see "Running" below)

Editor / assembler shell

SHELL_ENTRY from Wozmon enters it; its own > prompt takes command lines until QUIT returns to Wozmon's \:
  • 10 LDA #$2A store/replace line 10 (decimal, BASIC-style); bare 10 deletes it. Bad syntax is rejected on the spot with ?SYNTAX, not stored — labels aren't checked here, so forward references are fine
  • no leading number ⇒ auto-numbers onto the end (+10, like BASIC's AUTO)
  • LIST / LIST 100 — print the program, all or from line ≥100, 20 lines at a time
  • EDIT 30 — show then retype line 30; blank retype deletes it
  • ASM — two-pass assemble; errors report the real line number
  • RUN · LOAD / SAVE (see below) · NEW clears the program

Source line format

LABEL: MNEMONIC OPERAND  ; comment — one space between fields is enough; LIST/EDIT realign everything into columns regardless of how it was typed. ; starts a comment, ignored by ASM.

Memory map

$0000-00FF zero page · $0100-01FF stack · $0200-02FF ACIA RX ring · $0300-03FF Wozmon buffer · $0400-2BFF object code (~10.25K) · $2C00-2FFF symbol table · $3000-3FFF source (4K) · $8000-FFFF ROM

Running your program

Object code starts at $0400 — RUN goes there directly. No BRK trap: end with an explicit JMP $xxxx to return to the shell (its "home" now, not raw Wozmon). Ctrl-C breaks a program that never returns, via the ACIA's own receive interrupt — instant, whatever the program is doing. SW1 reset works too, but clears the program; Ctrl-C doesn't.

OS calls

Fixed addresses (bios.s's jump table) so a program can JSR them across ROM rebuilds. No .BYTE directive for string literals (see assembler scope) — build one byte-by-byte with LDA #$xx / STA first.
CallAddrInEffect
PRINT_CHAR$xxxxA=charprint to terminal
PRINT_STR$xxxxA/Y=strprint NUL-term string to terminal
LCD_PUTC$xxxxA=charprint to LCD at cursor

LCD_CLEAR$xxxx—clear LCD, home cursor

v1 assembler scope

Hex operands only ($xx/$xxxx — line numbers are a separate decimal concept); labels truncate to 6 characters; no indirect addressing ((zp,X), (zp),Y, (abs)); no 65C02 bit-ops (RMBx/SMBx/BBRx/BBSx); no ORG/.BYTE/.WORD (code assembles sequentially from $0400); no </> or label arithmetic. Documented cuts, not bugs.

Save / Load

Moves the program over the real RS232/ACIA link, same as typing SAVE/ LOAD at the shell (SHELL_ENTRY) by hand. Save dumps decimal-numbered text lines framed in STX/ETX; Load clears the program and streams one back in (auto-numbering unnumbered lines). Paced to the ACIA's real baud by default. Also driven from the Save/Load popup (terminal header).
