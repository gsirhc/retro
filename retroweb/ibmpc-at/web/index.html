Floppy drives

Two real 5.25″ drives, matching the genuine 5170: drive A is 1.2MB, drive B is 360KB. Mount a raw .IMG of exactly one of those two sizes -- 3.5″ formats (720KB, 1.44MB) and other 5.25″ densities aren't supported and will misread even if the file loads.

Software compatibility

Ships with FreeDOS 1.3 on C:, and runs real PC-DOS/ MS-DOS 3.x-era software the same way -- this is a genuine real-mode 80286, so nothing requiring protected mode (DOS 5+ memory managers, Windows) will run. Keyboard and the internal PC speaker only: no mouse, no sound card.
Disk images aren't included or hosted here -- commercial software remains copyrighted. You'll need to find your own compatible disk image (see Floppy drives above for the formats this machine's drives can read) and mount it yourself.
