# Built-in ROMs

The browser front end lists these entries in the **paper-tape reader**'s Load
dialog and fetches them from this directory at runtime.

| Entry | File | Source |
|---|---|---|
| Serial echo | `echo.bin` | generated by `gen_roms.py` |
| Hello, world | `hello.bin` | generated by `gen_roms.py` |
| Kill the Bit | `killbits.bin` | generated by `gen_roms.py` (Dean McDaniel, MITS, 1975) |
| Altair 8K BASIC 4.0 | `8kbas.bin` | `fetch-basic.sh` — flat load-and-go image, streams in |
| Altair 4K BASIC 4.0 | `4kbas.bin` | `fetch-basic.sh` — flat load-and-go image, streams in |
| Altair 8K BASIC (ROM build) | `8kBas_e0/e8/f0/f8.bin` | `fetch-basic.sh` — EPROM build, drops in (can't stream) |

`echo.bin` / `hello.bin` / `killbits.bin` are rebuilt by:

```sh
make -C web roms      # or: python3 web/roms/gen_roms.py
```

The BASIC images (`*.bin`, git-ignored) are pulled in — pinned and SHA-256
checked — by:

```sh
./web/roms/fetch-basic.sh       # --force to re-fetch
```

CI runs this before deploying to Pages, so a fresh clone or the live site needs
nothing extra.

`manifest.json` is the catalog the dialog reads. Per entry:

| key | meaning |
|---|---|
| `name` | shown in the list |
| `file` | single image, fetched from `roms/` |
| `files` | ordered list, fetched and **concatenated** (for a ROM split across PROM images) |
| `load` | address the image is written to |
| `start` | initial PC |
| `description` | shown in the dialog |
| `optional` | greyed-out "not installed" when the file(s) are missing, instead of hidden |
| `basicRom` | marks the 8K BASIC EPROM entry (relocates itself, can't stream) |

## BASIC game listings (`games/*.bas`)

`games/` holds plain-text 8K BASIC listings (Lunar Lander, Hunt the Wumpus,
Super Star Trek, Hammurabi, Hurkle — classic type-in programs). They are **not
wired into the UI** — there is no reader-dialog entry for them. Super Star Trek
is playable via the 88-ACR cassette (`tapes/startrek.cas`) and the CP/M "CP/M
Games" disk. The listings are kept here for a possible future "type a program
in" menu; each line is ≤72 chars (the 8K BASIC input-buffer limit).

## Altair BASIC (4K and 8K)

Fetched by `fetch-basic.sh`. Three images:

**`8kbas.bin` / `4kbas.bin`** — the **load-and-go** images: a flat binary of
Microsoft BASIC 4.0 that runs at `0x0000` (8192 and 3833 bytes), built for the
88-2SIO console (ports 10h/11h). This is what the real paper tape held. The
paper-tape reader keys a serial bootstrap into the top of RAM, runs it, and
streams the tape in through the 88-2SIO — 128 blank leader frames, then the
image — at "Realistic" speed (10 B/s, an ASR-33 reader) 8K BASIC really does
take ~14 minutes, exactly as it did. Cold start: `MEMORY SIZE?` /
`TERMINAL WIDTH?` / `SIN?` (8K: `SIN-COS-TAN-ATN?`), answer `Y` — the reader does
this for you. 8K BASIC needs ~12K of RAM; the Stock Launch preset sizes 4K BASIC
to a 4K machine so the memory test terminates at ~716 bytes free.

Source: nippur72/8-bit-projects `altair-basic/8kbas.bin` and `4kbas40.bin`.

**`8kBas_e0/e8/f0/f8.bin`** — Mike Douglas's **EPROM build** (four 2 KB PROM
images, from deramp.com). Concatenated into one 8 KB image at `0xE000`; the
first 24 bytes copy BASIC down to `0x0000` and `JMP 0`. Because it sits above
RAM it can't be streamed — the reader drops it straight in and cold-starts it.
Kept as an "instant" option.

To add any other program, drop its binary here and add a `manifest.json` entry.
