# Built-in ROMs

The browser front end lists these in the **Load Program** dialog and fetches
them from this directory at runtime.

| Entry | File | Source |
|---|---|---|
| Serial echo | `echo.bin` | generated by `gen_roms.py` |
| Hello, world | `hello.bin` | generated by `gen_roms.py` |
| Kill the Bit | `killbits.bin` | generated by `gen_roms.py` (Dean McDaniel, MITS, 1975) |
| Altair 4K BASIC | `4kbas.bin` | **you provide** (see below) |
| Altair 8K ROM BASIC | `8kBas_e0/e8/f0/f8.bin` | **you provide** (see below) |
| Lunar Lander, Hunt the Wumpus, Super Star Trek, Hammurabi, Hurkle | `games/*.bas` | classic BASIC listings (see below) |

`echo.bin` / `hello.bin` / `killbits.bin` are rebuilt by:

```sh
make -C web roms      # or: python3 web/roms/gen_roms.py
```

## Altair 4K BASIC

The **Stock Launch** preset wants `4kbas.bin` — a flat, *already-loaded* image of
**Microsoft 4K BASIC 4.0** (MITS 1976): the 3833 bytes that sit and run at
`0x0000`, built for the **88-2SIO** console (ports 10h/11h) — not the paper-tape
image with its checksum loader, and not the port-0 88-SIO builds. Microsoft 4K
BASIC was never public domain, so it's git-ignored (`*.bin`) and not bundled,
same as the 8K ROM.

The 4.0 image (identifies itself as `4K BASIC 4.0 / COPYRIGHT MITS 1976`) is on
the reproduction sites — deramp.com, altairclone.com, and various emulator
repos. Drop it in as `4kbas.bin`.

Cold start asks `MEMORY SIZE?` (Enter) → `TERMINAL WIDTH?` (Enter) → `SIN?`
(`Y`), landing at `OK` with ~716 bytes free in a 4 KB machine — the preset
answers those three for you and sizes RAM to 4 KB so the memory test
terminates. Without the file the preset still sets up the hardware and prints a
note explaining what's missing.

`manifest.json` is the catalog the dialog reads. Per entry:

| key | meaning |
|---|---|
| `name` | shown in the list |
| `file` | single image, fetched from `roms/` |
| `files` | ordered list, fetched and **concatenated** (for a ROM split across PROM images) |
| `load` | address the image is written to |
| `start` | initial PC |
| `description` | shown in the dialog |
| `optional` | greyed-out "not installed" when the file(s) are missing, instead of hidden |
| `basicRom` | marks the 8K BASIC entry — the source a `basic` program is typed into |
| `basic` | path (under `roms/`) to a BASIC listing instead of an image; see below |

## BASIC game listings (`games/*.bas`)

Star Trek, Lunar Lander and the rest are **BASIC programs**, not 8080 machine
code, so there is no ROM image. A `basic` catalog entry points at a plain-text
listing; the front end (`loadBasicProgram` in `app.js`) boots the 8K BASIC ROM,
answers `MEMORY SIZE?` / `TERMINAL WIDTH?` / `WANT SIN-COS-TAN-ATN?`, types the
listing in through the keyboard (metered against the 2SIO receive FIFO), and
`RUN`s it. The CPU runs faster than 2 MHz during the load and for a few seconds
after — Star Trek's galaxy setup is ~20 s of real 8080 time — then settles back;
the first keystroke also ends the sprint.

Every line must be **72 characters or fewer** — that is the 8K BASIC input-buffer
limit, and anything past column 72 is silently dropped. `_scratch`-style
normalisation (strip trailing spaces, drop blank lines, split/shorten long
`PRINT` lines) was applied when these were added.

Sources — all classic type-in listings, freely circulated for decades:

| Game | Origin |
|---|---|
| Lunar Lander | Creative Computing `ROCKET`, after Jim Storer's 1969 `LUNAR` |
| Hunt the Wumpus | Gregory Yob, 1973 (Microsoft-BASIC transcription) |
| Super Star Trek | Mayfield/Leedom; John Borders' 1978 Microsoft 8K BASIC port |
| Hammurabi | Doug Dyment 1968 / David Ahl's `BASIC Computer Games` |
| Hurkle | Creative Computing / `BASIC Computer Games` |

## Altair 8K ROM BASIC

The four `8kBas_*.bin` files (2 KB each) are Mike Douglas's ROM build of
Microsoft 8K BASIC 4.0. They are **git-ignored** (`*.bin`) — Microsoft 8K BASIC
has never been public domain — so keep your local copies. Re-download from
<https://deramp.com/downloads/altair/software/roms/custom_roms/8K%20ROM%20BASIC/>
if you need them again:

```
8kBas_e0.bin  8kBas_e8.bin  8kBas_f0.bin  8kBas_f8.bin
```

The dialog concatenates them into one 8 KB image at `0xE000`, PC `0xE000`. The
first 24 bytes there (`ROMLODR`) copy the 7424-byte BASIC down to `0x0000`, do
`OUT 0FFh` (a harmless ROM-disable on real hardware), and `JMP 0`. The `sense`
field is `0x00` so BASIC's cold-start reads the console as the 2SIO at
`10h`/`11h`. On boot: `MEMORY SIZE?` (Enter), `TERMINAL WIDTH?` (Enter),
`WANT SIN-COS-TAN-ATN?` (`Y`), then the `OK` prompt.

Verified: boots to `59012 BYTES FREE / ALTAIR BASIC REV. 4.0 [EIGHT-K VERSION]`;
`PRINT "2+2=";2+2` → `2+2= 4`.

> The paper-tape (`.tap`) BASIC images elsewhere on deramp.com are **not** flat
> binaries — they need the MITS bootstrap/checksum loader, which this emulator
> doesn't implement yet.

To add any other program, drop its binary here and add a `manifest.json` entry.
