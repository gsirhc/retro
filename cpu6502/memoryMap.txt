0x0000 - 0x004F = Reserved OS
0x0050 - 0x00FF = Available Zero Page
0x0100 - 0x01FF = Reserved Stack
0x0300 - 0x3FFF = User Program Space (~15K)
0x0300 - 0x3FFF = User RAM (minus program size)
0x4000 - 0x4FFF = Unavailable (not addressed)
0x5000 - 0x5FFF = ACIA
0x6000 - 0x6FFF = VIA
0x8000 - 0xFFFF = ROM
